# Portable API 3 audit — 2026-10-23

Target: official Gen1Recomp 0.3.96, Portable API 3. Manifest minimum is now 0.3.96; mod version unchanged.

## Contracts and fixes

- Inspected official Loader API3 dispatch and lazy public mod.game, Portable API3 documentation, generation compatibility, registry capabilities, UnifiedCallbacks/Records/World and native battle lifecycle.
- Gen3 and optional follower providers use public mod.game. There is no API3 mod.world.game. The GB renderer still uses the native compatibility data/locomotion view; live world selection resolves the public native game.
- Party submenu hook arguments and onSelect Pokémon are detached canonical records. PortableParty resolves the actual native party member and slot before closing the menu. Native cursor index is validated against the read-only diagnostic snapshot; unique fallback matches are accepted, ambiguous/stale selections refused. No writes go through detached records.
- Gen3 starts use public world:startWildBattle with canonical IDs; optional Double Battles withOrganicSource preserves scoped provenance across the newly created native descriptor. Busy/refused public calls are authoritative. The old Gold private battle fallback was removed; an intercepted flyer is restored through its owner API on refusal.
- Game3 remains phase=field during battles. Public battle.started/ended now drive mount/menu/music suspension and remount policy; no legacy phase=battle assumption remains in that path.
- GB portable script rows normalize Gen2 species aliases. Installed music reads are guarded by the public content/music capability. Options, hooks, events, custom event ownership, native screens and the Gen2 opt-in command/NPC helper were checked.

## Retained extensions / limits

Engine internals remain necessary for continuous free flight, altitude, mount sprite composition, camera integration, collision/ledge ownership and live native health/party identity: API3 has no arbitrary mounted entity/altitude service or stable party handle in submenu context. PartyMenu's native selected index is read and validated for identical party members.

Optional Stadium 2 provider adapters retain guarded private model/provider probes under engine_internals. DSM4 reads now use only Ride-owned mod.cache keys stadium2/... or owned package assets/stadium2/...; metadata uses public cache/assets info and invalidation uses cache.delete. The old Crystal-owned global cache is not retried or copied. A public cross-owner generated model-cache handle is unavailable; missing owned data fails closed to the existing public renderer-provider/2D fallback hierarchy. They are not described as portable API services. Optional Doubles source-only recruitment needs its new scoped export; without it public single battles remain standalone. The migration does not certify every external optional renderer/version. No version bump, publish or user cache mutation is part of this commit.
